# Tài sản thương hiệu

Đặt file logo, favicon chính thức của nhóm vào thư mục này, rồi khai báo đường dẫn trong
`src/config/brand.ts` (mục `brand.logo`). Không cần sửa file nào khác.

Hiện trạng:

| Tài sản | Trạng thái |
|---|---|
| Logo nền sáng | Chưa có. Website đang dùng logo chữ dự phòng |
| Logo nền tối | Chưa có |
| Favicon | `favicon.svg` là bản dự phòng (chữ cái đầu) |

Gợi ý định dạng: SVG là tốt nhất (nét ở mọi kích thước). Nếu dùng PNG, xuất ảnh cao ít nhất
96 px và có nền trong suốt.
